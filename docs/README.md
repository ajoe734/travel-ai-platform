## 正確使用這份文件包

原始規格是需求來源；研究報告是後續設計的歷史記錄；本次 SD 是對齊版本與補足缺口的工程設計。可操作的 HTML 仍然是模擬原型，沒有正式後端或第三方交易能力。

原始 Word／PDF 保留完整圖像與版面；Markdown 保留正文與表格，圖像位置有提示。找回任何歷史附件時，先新增來源與校驗紀錄，再比對現行設計，不直接覆蓋。
